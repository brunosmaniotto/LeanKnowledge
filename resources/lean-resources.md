# Lean 4 Resources

## Video Tutorials

- [Lean 4 Tutorial — Kevin Buzzard](https://www.youtube.com/watch?v=JHEO7cplfk8) — Introduction to Lean 4 by one of Mathlib's core contributors
- [Lean 4 Crash Course — Jeremy Avigad](https://www.youtube.com/watch?v=cyyR7j2ChCI) — Fast-paced overview of Lean 4 for mathematicians

## Written Tutorials

- [Mathematics in Lean](https://leanprover-community.github.io/mathematics_in_lean/) — Official interactive tutorial for formalizing math in Lean 4 with Mathlib
- [Theorem Proving in Lean 4](https://lean-lang.org/theorem_proving_in_lean4/) — Official reference for Lean 4 as a proof assistant
- [Functional Programming in Lean](https://lean-lang.org/functional_programming_in_lean/) — Lean 4 as a programming language (useful for metaprogramming / tactics)
- [Natural Number Game](https://adam.math.hhu.de/#/g/leanprover-community/NNG4) — Interactive game to learn Lean 4 proofs from scratch

## Mathlib

- [Mathlib4 Documentation](https://leanprover-community.github.io/mathlib4_docs/) — Full API docs for Mathlib (207K+ declarations)
- [Mathlib Naming Conventions](https://leanprover-community.github.io/contribute/naming.html) — How lemmas are named in Mathlib (critical for avoiding hallucinated identifiers)
- [Loogle](https://loogle.lean-lang.org/) — Search Mathlib by type signature (like Haskell's Hoogle)
- [Moogle](https://www.moogle.ai/) — Natural language search over Mathlib

## AI + Lean

- [LeanDojo](https://leandojo.org/) — Tooling for training ML models on Lean proofs
- [Goedel-Prover](https://huggingface.co/Goedel-LM/Goedel-Prover-V2-8B) — Open-weight model fine-tuned for Lean 4 proof generation (used in this project)
